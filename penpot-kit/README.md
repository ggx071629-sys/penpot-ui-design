# Penpot AI Kit

当前工作区的 Penpot 设计工具集，提供可编辑设计、组件与样式复用、可访问性检查、规范审阅和设计交接能力。

- `AGENTS.md`：操作规则。
- `skills/`：12 个技能及其参考资料、脚本。
- `workflows/`：6 个设计流程。
- `shared/`、`policies/`：设计规范、工具参考和审批要求。
- `prompts/`、`templates/`：需求简报及通用配置模板。
- `docs/`：技术参考和故障排查。

从工作区根目录的 [README](../README.md) 开始，使用前遵循 [AGENTS.md](AGENTS.md)。安装与维护以[工作区维护说明](../docs/maintenance.md)为准；生命周期入口保持禁用。
